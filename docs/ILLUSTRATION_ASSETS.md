# Original Forest & Butter illustrations

These static SVG sources were created in code for TastePassport from the approved visual direction:

- `public/illustrations/passport-journey.svg` — passport, globe, route, sun and leaves for onboarding and the Passport cover.
- `public/illustrations/together-passports.svg` — two passports for the Together introduction.
- `public/illustrations/city-garden.svg` — city-neutral outlines, route and botanical page-edge artwork.

No stock illustration, external image embed, city photograph or trademarked third-party logo is included. Distribute these project assets under the repository's MIT license and retain its license notice. No separate stock-image purchase or attribution is required for these assets. This does not assert exclusive copyright protection for generated artwork or grant rights to third-party Qloo photographs. Manrope retains its existing OFL notice in `public/fonts/OFL-Manrope.txt`; Qloo image usage remains subject to the relevant provider rights and terms.

The three SVGs total about 5.1 KB uncompressed, have explicit dimensions, and contain no scripts, embedded fonts, animations or external resources. Decorative images use empty alt text and do not handle clicks. Forms/cards remain on solid surfaces; cover colors match the approved warm ivory and forest direction. Mobile layouts reduce ornament size, and print layouts hide the decorations. The skyline is deliberately city-neutral so it does not claim a particular landmark belongs to the selected destination.

These are static original artwork assets, served with the app. Rendering them makes no image-generation or Qloo API request. Actual recommendation photos still come only from Qloo-returned image URLs.
