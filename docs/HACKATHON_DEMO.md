# TastePassport demo

**Move anywhere. Keep your vibe.** A taste profile becomes an evolving bridge into a new city, rather than a list of keyword search results.

## A three-minute journey

1. **Your world (30s).** Choose a supported destination, enter three real interests and explicitly confirm Qloo matches. Toronto with A.R. Rahman, Interstellar (2014) and Indian cuisine is a reproducible input example, never a canned result set.
2. **Your new chapter (40s).** Show real discoveries across available categories. Open the cultural connection story: actual confirmed inputs → Qloo query → actual returned results. Explain collective provenance; do not attribute a venue to one film without evidence.
3. **Make it yours (40s).** Switch one category from Familiar to Explore. Show actual changed discoveries, retain a My Vibe choice and reject another. Other chapters stay intact. Availability of results depends on Qloo coverage.
4. **Do something with it (40s).** Open My first weekend. Replace a single stop, keep the others and download the plan. Explain that users verify hours/travel and that no reservation is made. Missing local categories remain open rather than being fabricated.
5. **Show the agent (30s).** With a healthy model, ask for independent contemporary art connected to film tastes. Show safe backend function/tool events and confirm any ambiguous tag. If Gemini is unavailable, demonstrate guided refinement transparently. Only show same-request baseline comparison after it genuinely succeeds.

## Technical explanation

Gemini interprets intent and selects native function calls. Deterministic catalog operations use validated Qloo HTTP requests; dynamic supported workflows use the official harness/MCP integration. Shared session state retains confirmed tastes, feedback and category constraints. Qloo supplies discoveries; the app supplies continuity, explicit control, traceable connections and an actionable sequence.

Enable metadata-only backend logs with `AGENT_DEBUG=1`. Use the event names in [the debugging guide](FLOW_AND_DEBUGGING.md). Never show credentials, raw environment files or provider response dumps during the demo.
